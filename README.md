# Paper Guide Annotator

一个用于学术论文“首次通读”的 Codex skill。它会在保留原论文内容、公式、图表和图片的前提下，生成带有中文导读、关键句高亮、选择性批注以及批判性总结的 PDF。

它不是逐句翻译工具，而是希望先替读者把论文讲一遍：先建立整体脉络，再解释真正影响理解的细节，最后评估论文的贡献、证据和局限。

## 主要功能

- 在论文前加入中文导读、简明摘要、章节脉络和阅读建议。
- 高亮研究问题、核心主张、关键假设、方法选择、主要结果和明确限制。
- 对概念、公式、图表、实验设计以及省略的推理步骤做中文批注。
- 区分“论文主张”“理解辅助”和“批判性评价”，避免把 AI 推断写成作者结论。
- 将批注中的数学表达式渲染成排版完成的公式，不在成品中暴露原始 LaTeX。
- 在论文末尾总结贡献、假设、证据强弱、适用范围、局限和后续问题。
- 渲染并检查最终 PDF，避免高亮或批注遮挡、裁切原始内容。

## 默认阅读配置

当用户没有另外指定时，skill 使用以下默认值：

| 选项 | 默认值 |
| --- | --- |
| 读者水平 | 第一次阅读该论文的研究生 |
| 批注密度 | 标准、选择性批注 |
| 阅读目的 | 理解方法与论证，并评估优点和局限 |
| 输出语言 | 中文，重要术语首次出现时保留英文 |
| 外部资料 | 仅在明显有助于理解时补充，并与论文原文区分 |

## 高亮规则

高亮是独立的 PDF 注释层，不应修改底层文字。默认颜色含义如下：

| 颜色 | 含义 |
| --- | --- |
| 黄色 | 核心主张或定义 |
| 蓝色 | 方法或关键假设 |
| 绿色 | 主要结果或支持证据 |
| 橙色 | 限制、保留条件或适用范围 |

高亮强调“少而准”。并非每一页都必须有高亮，也不应为了显得详细而涂满整段文字。

## 数学公式

LaTeX 可以作为公式的中间编写格式，但最终 PDF 必须显示排版完成的行内或独立公式。公式应优先使用矢量输出或嵌入数学字体，以便放大和打印时保持清晰。

成品不应出现未渲染的 `$...$`、`\\frac`、`\\sum` 等命令，也不应使用公式截图。若某个公式无法可靠渲染，应引用论文中的公式编号并用文字解释，同时说明限制。

## 安装

将整个仓库复制或克隆到 Codex 的个人 skills 目录中，并确保目录名为 `paper-guide-annotator`：

```text
~/.codex/skills/paper-guide-annotator/
```

Windows 上通常对应：

```text
C:\Users\你的用户名\.codex\skills\paper-guide-annotator\
```

安装后，Codex 应能发现 `$paper-guide-annotator`。如果当前会话尚未显示它，请重新打开会话或刷新可用 skills。

## 使用示例

基础用法：

```text
$paper-guide-annotator 帮我给这篇论文生成中文导读批注版 PDF。
```

指定读者和批注深度：

```text
$paper-guide-annotator 按入门读者、深入批注的方式处理这篇论文，重点讲公式和实验设计。
```

面向复现：

```text
$paper-guide-annotator 阅读这篇论文并生成批注版 PDF。我的目标是复现实验，请重点解释数据、关键假设、基线、评价指标和消融实验。
```

可以在请求中调整：

- 读者水平：入门、研究生或同领域研究者；
- 批注密度：精简、标准或深入；
- 阅读目的：快速了解、复现、文献综述、研讨会准备或批判性审读；
- 数学讲解深度；
- 是否补充外部背景和参考资料。

## 输出结构

典型输出 PDF 由三部分组成：

1. 文前导读：AI 摘要、问题背景、核心方法、贡献、章节路线和预备知识。
2. 原论文页面：保留原内容，加入透明高亮和不遮挡正文的中文批注。
3. 文末评价：贡献、假设、证据、局限、适用范围和二次阅读问题。

原始 PDF 不会被覆盖。

## 运行要求

- 能够读取、生成、渲染和检查 PDF 的 Codex 环境。
- 可用的 PDF skill 或等价 PDF 工具链。
- 对扫描版论文进行处理时，可能需要 OCR；高亮位置必须经过视觉检查。
- 加密、损坏、字体嵌入异常或页面结构极其复杂的 PDF 可能无法完全可靠地处理。

## 开发与校验

修改 skill 后，可以使用 Codex 自带的 skill 校验脚本检查目录结构和 frontmatter：

```powershell
python -X utf8 "$HOME\.codex\skills\.system\skill-creator\scripts\quick_validate.py" "$HOME\.codex\skills\paper-guide-annotator"
```

结构校验通过并不代表生成的 PDF 一定正确。实际使用时仍需渲染最终 PDF，并检查高亮位置、中文字体、公式、页面映射和原文完整性。

## 设计原则

- 保留原文优先于批注便利性。
- 解释关键节点，而不是逐句复述。
- 批评必须对应具体假设、证据、结果或页码。
- 不确定的解释应明确标注。
- 公式必须完成渲染，高亮和批注不得降低原文可读性。
